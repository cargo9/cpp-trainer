# C++ Тренажёр: офлайн-приложение для iPhone

55 задач в стиле LeetCode, 5 уровней (Разминка → Лёгкий → Средний → Сложный → Про).
Пишешь код прямо в телефоне, жмёшь «▶ Проверить», и настоящий компилятор Clang 22
(собранный в WebAssembly) компилирует и прогоняет автотесты на самом iPhone. Без сервера и без интернета.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс, редактор с подсветкой, панель символов над клавиатурой |
| `problems.js` | задачи: условие, стартовый код, тесты, подсказка, эталонное решение |
| `harness.js` | генерирует `main()` с тестами и разбирает результаты |
| `compiler-worker.js` | держит Clang в фоне и компилирует C++ → WebAssembly |
| `run-worker.js` | запускает программу, убивается по таймауту (бесконечный цикл не повесит приложение) |
| `sw.js`, `manifest.webmanifest`, `icons/` | офлайн-режим и установка на экран «Домой» |
| `vendor/` | компилятор Clang/LLD (пакет `@yowasp/clang`), предкомпилированные заголовки STL |

Весь размер около 125 МБ, почти всё это компилятор. Скачивается на телефон один раз.

## Как поставить на iPhone

Сервис-воркеры (офлайн) работают только по **https**, поэтому папку нужно один раз выложить на любой статический хостинг.
Самый простой вариант — Netlify:

1. Зайди на https://app.netlify.com/signup и зарегистрируйся (бесплатно, можно через GitHub или Google).
2. Открой https://app.netlify.com/drop и перетащи туда **папку** `cpp-trainer` целиком (или архив `cpp-trainer.zip`).
3. Netlify выдаст адрес вида `https://что-то.netlify.app`.
4. На iPhone открой этот адрес **в Safari**.
5. Нажми «Поделиться» → «На экран «Домой»» → «Добавить».
6. Открой приложение **с иконки на экране «Домой»** (важно: у установленного приложения своё хранилище, отдельное от Safari).
7. На главном экране нажми «⬇︎ Скачать» (лучше по Wi-Fi). Когда появится «✓ Работает офлайн», интернет больше не нужен.

Проверка офлайна: включи авиарежим, открой приложение с иконки, реши задачу.

Другие хостинги тоже подойдут (GitHub Pages через `git push`, Vercel). Cloudflare Pages не подойдёт:
у него лимит 25 МБ на файл, а `llvm.core.wasm` весит 75 МБ.

## Как пользоваться

- **Условие / Код / Результат** — вкладки на телефоне. На планшете и компьютере всё видно сразу.
- Писать `main()` в задачах не нужно, его добавляет проверка. В **Песочнице** наоборот: свой `main()` и ввод через stdin.
- Подключать заголовки необязательно, весь STL уже подключён, но `#include <bits/stdc++.h>` и `using namespace std;` в шаблоне оставлены как привычка.
- Ошибка компиляции подсвечивает строку; нажми `main.cpp:12`, чтобы прыгнуть к ней.
- На уровнях «Сложный» и «Про» есть тесты на скорость: решение O(n²) там упрётся в лимит 10 секунд.
- Прогресс и код хранятся только на этом устройстве.

## Ограничения

- Исключения: `throw` компилируется, но не перехватывается (`catch` не сработает), программа завершится с понятной ошибкой.
- Глубина рекурсии ограничена движком браузера: примерно 5–10 тысяч вложенных вызовов. Для больших графов используй BFS/стек вместо рекурсии.
- Первая проверка после запуска приложения дольше (компилятор загружается в память), дальше 1–3 секунды.
- Нужен iOS 16.4 или новее.

## Как добавить свою задачу

Скопируй любой объект в `problems.js` и поменяй поля:

```js
{
  id: 'myTask', lvl: 2, title: 'Моя задача', fn: 'solve', args: ['vector<int>', 'int'],
  desc: '<p>Условие…</p>',
  starter: 'int solve(vector<int>& a, int k) {\n    return 0;\n}',
  tests: [[['{1,2,3}', '2'], '5'], [['{}', '0'], '0']],   // [[аргументы], ожидаемый результат]
  hint: 'Подсказка', sol: 'int solve(vector<int>& a, int k) { … }',
}
```

После правок увеличь номер `SHELL_CACHE` в `sw.js` (например `v2`), чтобы телефон подтянул новую версию.
